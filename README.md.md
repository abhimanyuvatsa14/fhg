# **Shards of Light**

###### Shards of Light is a top-down 2D maze game we are developing in the Godot Engine. The core experience centers around tension and visibility—players are dropped into a dark maze with only a limited light radius surrounding them, forcing careful exploration and quick decision-making.





#### **Project Description**



##### The goal of the game is simple on paper but challenging in execution: you must navigate a series of complex top-down mazes to find the exit. Because your vision is restricted to a tight radius around your character, you never quite know what is waiting for you around the next corner.To make things interesting, the mazes are populated by enemies that will deal damage if they catch you. Survival requires a mix of stealth, routing, and speed. To help you along the way, we have designed collectable boosts scattered throughout the environment that give you temporary speed bursts or restore lost health.We wanted the game to be accessible but challenging, so it features three distinct game modes: Easy, Normal, and Hard. Each mode scales the difficulty to test your spatial awareness and reaction times.

#### **Tech Stack**



##### We chose our tools to keep the development fast, lightweight, and focused on clean 2D gameplay:

* ##### Game Engine: Godot Engine, utilizing its built-in 2D rendering and dedicated 2D lighting systems (like canvas modulation and point lights).
* ##### Programming Language: GDScript, which allows us to rapidly prototype our player movement and enemy tracking logic.
* ##### Version Control: Git and GitHub Desktop, which we use to merge our scenes and track updates line-by-line.







#### **How to Run the Project**



#### If you want to pull the project down and test it out locally, you can follow these steps:

* #### Ensure you have the stable version of the Godot Engine installed on your computer.
* #### Clone this repository using GitHub Desktop or via the command line.
* #### Open the Godot Project Manager, click the "Import" button, and navigate to this folder to select the project.godot file.
* #### Once the project loads in the editor, simply press F5 or click the play button in the top right corner to run the game.
